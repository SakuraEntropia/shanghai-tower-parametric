重建：

```bash
blender --background --factory-startup --python-exit-code 1 --python scripts/build_shanghai_tower.py -- --render --views 01,02,06,07,11,12,13,14,15,17,18,19,20,21,22,23,24,25
python3 -m unittest discover -s tests -q
blender --background model/shanghai_tower_evidence.blend --python-exit-code 1 --python scripts/inspect_saved.py
```

本次运行环境Blender5.2Alpha；脚本兼容旧Nishita/新Single Scattering天空枚举，其他版本应重跑检查。改参数后需重建，不可只移动渲染图。

取得施工图级精度仍需：裙房竣工总平面/各层平立剖及PR全套断面/加工单；轴9及PG1/2/3边界/节点；2025艺术厅/雕塑/棚顶竣工图；冠部孔洞和Windpods机电定位；内B幕墙底部节点/钢梁表；完整楼层对应表/实测北向。
