# v6 塔冠：开孔、钢网、TMD 大厅与设备

本次撤回 v5「矩形槽连接半圆端」解释。Gensler 实际航拍中，中央为**矩形下沉井内的完整圆洞**；外围屋顶为金属格栅，并有零散方孔、圆孔。v6 用真实缺面/格栅几何表示这些关系。照片未经相机标定；孔位、尺寸、格栅间距及设备排列均为**待确认的可替换候选**，不宣称竣工尺寸一致。

所有候选集中在 `parameters/crown_v5.json`；外冠风口与疏化框架接口在 `parameters/completion.json` 的 `crown` 中。坐标单位为米，XY与既有模型一致；s沿同一开放母轮廓累计弧长，高唇/低唇保持原实际V接口。候选坐标并非相机校准测量，无法给出可信有限空间误差，保留未界定系统误差。

外冠玻璃仍采用三角形做显示曲面，但框架仅沿原四边形边界生成，**不把三角剖分对角线画成真实钢架**。竖框每三条采样线、横框每两条显示带抽样，管半径0.035m均为显示候选。主承重桁架与显示玻璃框分集合，减少重复包覆；不把显示抽样当施工幕墙pattern。

## 场景内说明与核验

新增 `78_TMD_ART_HALL_CANDIDATE` 与 `79_CROWN_WIND_TURBINES_CANDIDATE`。每个构件保留来源ID、公式、证据级别、未知坐标/尺寸声明；`asbuilt_verified=false`。已证实的1000吨、270台、583.4m单独存属性，不把整个候选构件升级为已证实。

大厅实体自带583.4m环形访客楼板。此前F126/F127/F128实体楼板代理会切入公开大厅，集成时归档隐藏，保留其楼层计数与来源；F125仍在下部，F129旧顶板继续由新格栅屋顶替代。悬索连质量块与上部框架，磁体在质量块下、铜板在其下；没有将TMD建成另一座建筑的球形装置。

视图检查发现原通用径向杆端点r6m侵入新公开大厅及天空圆洞。v6将583.2m以上至屋顶下方的候选径向杆内端截到大厅半径16.7m之外另加0.25m显示净空，保留其下各层连接。杆件包络至少距大厅边界0.15m；这是避免代理构件冲突的接口约束，不声称已取得真实节点。屋面格栅显示候选节距0.18m、条宽0.075m，投影覆盖约66%，让航拍中的细密金属屋面及独立杂孔能读清；数值未经图像标定，不能作为实际格栅加工尺寸。

本模块纯几何回归涵盖：高/低V唇、内冠生成线中点共线、井内全圆均无遮挡、270台生成计数、冷却塔来源冲突属性、实际缺面风口、抽样框数量、磁体/铜板关系、屋面下钢杆包络、默认隐藏独立停机坪。纯测试通过只证明脚本关系成立，不能证明施工真实性；Blender实景和对照视图由主装配核验。

进一步精确化仍需：塔冠竣工平/剖/钢结构加工图、风口与270风机布置表及改型产品图、屋面格栅/井/孔/设备深化图、TMD机电安装与艺术厅竣工图、停机坪是否存在及许可/图纸证明。缺这些资料时，v6只能达到上述来源支持的关系精度。
