# v3实体补齐与精度

v3补齐楼板、夹层幕墙支撑、巨型框架、底商候选体及冠部屋面钢构。实体增加不等于竣工参数已获；各对象保留来源、公式、误差和`asbuilt_verified=false`，冠部候选构件另标`approximation=true`。集中输入为`parameters/assembly_v3.json`。

楼板采用129个候选编号：S13 PDFp12 Fig6的18处监测标高照录；中间层按源局部编号线性插值，最低四层为显示值；顶段采用NTUA PDFp13 Fig8图测。原始标高虽有据，将其用作楼板顶面仍为推导。所有编号的`floor_crosswalk_status=unresolved`，129不代表实际地上层数；业主127与其他资料128的计数冲突仍保留。圆形楼板留核心开孔；厚度参考B14_STRUCT p38办公155mm、设备/公共层200–250mm，所用225mm是区间内候选，楼层用途映射尚未确认。

夹层CWSS增加环管、径向撑、吊杆及候选连接实体。B14_CWSS支持其支承、悬挂和变形释放逻辑，已发布管径/壁厚可直接作截面尺寸；每个杆件的安装坐标、吊点数量、节点偏心和楼层归属仍为推导或显示选择。几何接上内外层不等于节点已达到深化精度。

巨柱、角柱、环带及伸臂按D10 p2–3体系和Table1参考值表达。外围承力结构是巨型框架，不能称连续RC外筒墙。尺寸保持2010版标签；沿高度的截面分配、轴线位置和各加强层定位为候选，钢骨与钢筋未完整复原。

底商采用D10 p2早期七层、38m名义依据；Gensler早期五层方案并列登记。公开资料未给可靠外边界及连接缝，因此平面范围、层高分配、门窗与塔楼接口均为可调显示候选，不得称真实商场边界。

幕墙余高补片与边界接缝补齐可见空带。它们是对候选表皮的几何连接，不继承标准区已核验pattern等级。真实设备/避难层开口、V槽、净玻璃尺寸及边缘节点仍缺证，补片不得自动解释为竣工玻璃分格。

塔冠增加约601.099m内屋面、核心开孔、曲面集水壳及外侧垂直桁架、径向撑、kicker、转角支撑和隔层水平桁架。依据NTUA p13–14 Fig8–9和Gensler B14 p19；632m处保持开放，不加平盖。图测标高候选约±1.5m；屋面半径、周向剪裁映射、孔洞、杆件截面/数量和部署均待确认。源图的内屋面谷底不能误作外周最低裁边。

已证实的是公开名义尺寸、技术表值和设计构造原则；推导的是图测位置、插值标高及版本映射；待确认的是施工坐标、节点、局部开口和显示参数。核验只证明生成几何符合当前输入，不能证明与实物完全一致。后续须取得统一楼层表、A/B墙CAD、核心开洞图、裙房定位及塔冠/幕墙竣工深化资料，才能接近施工图精度。
