# 实现参数增补：建筑输入与显示约定

本轮源参数仍为 `parameters/parameters.json` 的94项。实际生成配置为 `parameters/model_config.json`；本表登记新增约定，不把显示尺寸升级为建筑实测值。

| 参数/配置 | 当前值、单位 | 证据等级 | 来源/推导 | 不确定性与影响 |
|---|---|---|---|---|
| geometry_version | gensler_2014_reconstruction | 推导值 | B14_GEOM p15–16 | 采用45–632m、剩余比例0.55的条件解释；不是竣工脚本 |
| theta0 / direction | 0° / +1 CCW | 待确认 | WP1局部软件坐标约定 | 北向/真实方向未知，影响全部方位；非测量值 |
| reference_line_kind | glass_control_assumed | 待确认 | G01/B14图示默认轮廓解释 | 不再对外幕墙加400mm偏心；工作点类别未统一 |
| control/guide bevel radius | 0.35 / 0.18m | 显示采样，非真实杆径 | 使控制线在全塔视图可见 | 不用作建筑尺寸或控制坐标误差 |
| perimeter sampling | 288点；线框高度步距4.5m | 显示采样，非建筑尺寸 | 解析圆弧离散与显示需要 | 不是幕墙分格点，也不是逐层楼板位置 |
| main half grid | 6×23；分组2/6/6/6/3 | 规则已证实；位置推导 | B14_GEOM p18；各半角等弧长插值 | 各组真实弧长/端点未知；V口排除；不能称最终138板 |
| excluded segment | K2整圆角弧 | 待确认区域的显示保护 | G01/B14缺口位于此局部；准确边界未知 | 整弧留空是保守排除，显著大于可能实际缺口；不代表V口施工尺寸 |
| standard band pitch | 4.5m | 名义标准值有据；位置推导 | B14_CWSS pp50–52；各参考区从底采样 | 非逐带实测标高；剩余区间留空；设备层/区界不套普通模板 |
| vertical rectangle anchor | 上端毛控制弦向下挤出 | 推导值 | Y19直立平面矩形与阶梯；研究约定 | 毛单元宽高不等于玻璃加工净尺寸；上/下端工作点算法未取得 |
| frame face width | 50mm | 待确认显示占位 | 无型材正面宽批准图 | 只使框条可见，不用于精确幕墙验收 |
| horizontal frame depth | 100mm | 待确认显示占位 | 无完整型材截面 | 几何表意，不是真实截面 |
| historical mullion depth | 114mm | 已证实历史设计值 | G01 p15 | 限2010样件；主塔框架如采用同一系列需附跨版本假设，后期型材表未知 |
| historical glass fin | 厚26mm、深度上限300mm | 已证实历史设计值 | G01 p15 | 300为上限示范，不代表每区均此深；主塔默认不铺满玻璃翅 |
| glass material thickness | 外25.52mm候选 | 来源配置已证实；分配待确认 | K16 p2 / Y19 | Solidify名义厚度不证明区域、热处理、镀膜与玻璃净边 |
| core display arm fraction | 1/3 | 待确认显示占位 | 九格/十字仅拓扑有据；原尺寸表未知 | 不等于真实臂宽或9个等室；高区线框不生成真墙 |
| core display zones | S13加强层参考边界 | 参考标高已证实；适配待确认 | S13 Fig1b | 不证明核心准确转换标高；顶部展示范围573.90非核心真实顶 |
| CWSS display rod length | 8m | 待确认显示约定 | B14_CWSS径撑8–10m为间距，不用其证明该长度 | 独立构造样件，仅表连接方向；塔身径撑定位未知 |
| hanger pair separation | 0.35m | 待确认显示占位 | 未取得节点加工图 | 不代表真实双吊杆净距 |
| detail/sample origin | 幕墙(160,0,35)，CWSS(160,-30,70)m等 | 显示平移 | 软件展台约定 | 不属于塔楼实际坐标；样件集合独立可隐藏 |
| slab diameter specimens | 82.2 / 46.5m | 已证实设计端径 | B14_STRUCT p32 | 单独圆板/轮廓样件，不插值生成全楼真实楼板 |
| materials/lights/cameras | JSON显示设置与脚本值 | 显示约定 | 可视化需要 | 未做实物光学参数拟合；颜色不是幕墙材料批准色号 |

模型对象的 `evidence_level` 描述实际生成几何；`source_parameter_evidence`（如有）、`formula`、`uncertainty`、`geometry_role`、`asbuilt_verified`补充限制。对象/面与逐板台账共同追溯，不因为某个截面名义尺寸有据便把未知位置一起标为精确。

原始来源分歧全部保留。图像未校准区域不输出像素测量值，也不报告未知建筑公差为±0。软件数值阈值与资料精度分开。
