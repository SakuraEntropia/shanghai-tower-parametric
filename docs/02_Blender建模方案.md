> 阶段一、二建模前快照。当前生成与核验结果见 `05_模型使用与核验.md`。

研究日期：2026-10-10（Asia/Singapore）。状态：设计方案，尚未生成模型。对应参数、来源、争议记录见同目录阶段一报告及 `parameters/parameters.json`。

## 1. 精度目标与采用路线

采用公开技术资料支持的分部件重建。实体尺寸、图像推导、资料空缺分别管理；“已证实”只证明某一来源及版本记载该值，并不自动等于竣工测量。几何、幕墙与结构的跨版本适配另作记录。

可选路线比较：

| 路线 | 能达到的程度 | 条件与代价 |
|---|---|---|
| 公开技术资料重建（推荐） | 已公开的设计尺寸可核验；有图纸约束的曲线与局部分格可推导；缺失节点保留接口 | 可开始可编辑研究模型，但不能声称施工图级或全楼与实物一致 |
| 竣工图/BIM驱动 | 可逐层逐板复现并计算与竣工坐标的残差 | 需要业主、Gensler、同济及幕墙单位提供完整文件和版本映射 |
| 摄影测量辅助 | 对可见轮廓、局部面板与裙房作独立校验 | 需要可校准的高分辨率影像；当前照片缺镜头/站位/尺度，不采用为精确尺寸输入 |

本轮完成阶段一、二。方案审阅后才进行阶段三、四。阶段三不是自动填补所有 `null`：缺口必须继续显式存在。

## 2. 场景单位、坐标和基准

- Blender `METRIC`，`scale_length=1.0`，1 Blender unit = 1 m；右手系，Z向上。
- 塔楼局部中心轴暂设X=Y=0，这是模型坐标约定。真实测量坐标、地理北向、首层初始朝向没有可靠数值，均保留 `null`，不得声称已地理定位。
- 三类标高不混用：建筑±0.000设计基准；论文图中的设计标高；CTBUH/CVU从最低主要露天人行入口量起的高度。它们之间的偏移量必须有依据，未确认前使用分开的参考层与标尺。
- 632 m为确认的建筑高度指标，不能直接等同“楼板挤出632 m”。塔冠和最后占用楼层单独处理。
- 楼层注册表逐条保存 `source_floor_label / source_version / normalized_floor_id / crosswalk_status / z / datum / zone / function / source / evidence`。统计127/128及可到达的126层不能替代楼层注册表。2013监测F51=239.40 m与业主运营52层约239 m提示楼号口径不同；对应表未取得时normalized_floor_id为null，禁止按数字楼号直接JOIN或推定全楼统一+1。
- 如需展示锚点之间的研究楼板，派生标高采用分段线性插值并逐层标为DERIVED，记录区段、端点、来源楼号和公式；这些平均间隔不是实际层高。没有足够输入时默认只生成有依据的稀疏楼层，保留完整层表接口。特殊层、设备层、裙房、塔冠及未知端点不允许外推。另登记2010/2014结构研究的124层统计及塔冠L129源标号，禁止自动映射到127/128建筑统计。

## 3. 塔楼轮廓与扭转

默认水平轮廓为Gensler图示的等边三角形构造、相切大圆弧与圆角、非对称V形收口。不能用直边圆角三角形、正弦三叶形或任意三角形替代。

主体相切圆弧函数定义为 `C_arc0(u; R1, L4, A1)`，缺口另定义为随高度变化的 `N(z,v; IR(z), endpoint_parameters(z))`。`u/v`采用各自曲段的拓扑参数，不将圆周等角分布误当原始曲线分格。原图数字88330、47665及23.3°分别入库；前两项单位解释为mm属于推导。圆弧内部相切推导及缺口约束见参数表，未识别的参数不设伪精确默认值。

每一高度的连续设计包络为：

`C_arc(z,u) = O + s(z) · Rz[theta(z)] · (C_arc0(u) - O)`；随后按该高度的独立缺口曲线N裁接主体圆弧，形成完整 `C_A(z)`。N不自动等比缩放。

这是模型公式；证明来源中采用指数缩放和线性旋转，不等于证明上述所有端点、轴向、系数及竣工坐标。

保留两个独立的设计版本：

| 版本 | 已读到的控制信息 | 建模限制 |
|---|---|---|
| Gensler 2010论文、2011文件版 | Fig.4：默认轮廓+45 m；+605 m控制轮廓；两者之间旋转120°、Scaling 55.86%；+632 m另列顶轮廓 | +0至+45以及+605至+632不默认沿用同一曲线；55.86%的语义须保留解释；原图Euler常数数值存在错误 |
| Gensler 2014章节 | p15：120°、55%；图注明缩放控制高度632000−45000=587000；文字描述指数缩放 | 单位解释及比例语义为推导；587 m是控制区间长度，不能当塔楼总高；不能与2010的+605控制点拼接 |

若采用“缩放值为剩余线性尺度比”的假设，令 `t=(z−z0)/(z1−z0)`、`s(z)=exp(ln(q)·t)`、`theta(z)=theta0 + direction·120°·t`。2010诊断版采用 `z0=45, z1=605, q=0.5586`；2014推导版暂候选 `z0=45, z1=632, q=0.55`。这两个函数均须标为“推导值”，不能称原始参数文件复现。另保留 `q=0.45`作为“减少55%”语义的敏感性比较，不能静默选择。最终选择需与多标高平面及原图校验。

若有逐标高控制点则直接优先使用；按控制点ID保持对应，旋转角按360°展开后插值，避免环绕跳变。完整轮廓因非对称缺口而没有120°周期。圆弧尽量解析求值，描摹曲线只用分段线性或保形插值；不使用会在缺口/退台处过冲的自由样条。

下部入口及顶部塔冠使用独立剖面列表，缺口的内层圆半径 `IR(z)`、95°角、收口转折均不能随主体等比缩放而自动假定。

## 4. 核心筒、楼板和主体结构

- 核心筒不是随外幕墙一起扭转的三角柱。采用固定结构平面坐标；Z1–4九格方核、Z5–6切角、Z7–8十字形及上部矩形按来源拓扑分区。
- 30×30 m是专业论文/章节记载的设计尺寸；TT项目介绍另写90×90 ft，保留冲突。九格不自动等于九个10×10 m净空房间。墙厚、墙中心线、洞口、电梯井、切角长度及截面切换的准确标高需逐项确认。
- 楼板采用内层圆形/分区板边与独立层高，不把外幕墙包络填满为每层板边。公开82.2→46.5 m圆楼板尺寸只有端点/范围意义，逐区收分与过渡尚缺。
- 主体外部巨型框架：8根巨柱、下部4根斜柱、8组两层高双环带桁架（每组两条平行环带）及6组两层高伸臂。伸臂连接核心筒与巨柱；它们与跨中庭的幕墙径向撑是两个系统。
- 155 mm办公组合楼板以及200–250 mm机电/amenity范围属于公开设计信息。不能覆盖全部楼层、开洞或底部厚板。
- 连接节点、柱坐标和逐层截面表缺失时采用接口/明确标记的占位，不把巨柱两端截面作线性插值后称真实构件。

## 5. CWSS与内外层空间

外幕墙A为围护表皮；内幕墙B围合实际使用空间；主体外框为承重结构。分别管理位置与荷载连接，禁止用“内外两个承重筒”简化关系。

优先使用2014同济幕墙章节描述的Z2–Z8标准CWSS：连续环梁、径向撑、双吊杆、相切处限位、角部交叉拉杆和底部竖向滑移。2010版八道水平伸缩缝保留为历史记录，不用于后期方案。

每个分区吊杆从其顶部机电/避难层承载构架向下悬吊环梁；径向撑连接环梁与内层板边并允许规定方向的位移。具体承载层、节点角度与杆件位置以注册表为准，不能把一种连接全高阵列。间距8–10 m、管径及壁厚是设计范围，不能用范围均值构造“真实坐标”。

24/25吊点记录单独保留；不得用等角24点填满全楼。内外表皮的径向间距按同一局部中心、同一方位射线与A/B轮廓的交点半径差计算；另可记录最短表皮距离，两项分开命名，不能将任意u/v点直接相减。玻璃净间距还应扣除框架/节点占用。B幕墙每区竖直、在区界退台，不跟A逐层扭转。Z1和Z9另用规则。

## 6. 幕墙 pattern 的几何生成

详细输入见 `03_幕墙pattern专项.md`。分格是面板拓扑、位置与类型规则，印刷frit另作材质/可选细节，不能用贴图替代板缝、竖梃、横框和玻璃翅。

生成次序：

1. 按版本装入各分区A/B轮廓和楼层/环梁标高；选定每层分格拓扑及V口例外。
2. 在基准圆弧上按原资料的分段/弧长规则布置控制点，保存点ID、曲段、相位、板型。144、141、138的冲突未解决前不输出“竣工全楼分格”。
3. 将相邻标高轮廓缩放、旋转；按正放竖梃和错台/水平stack joint方案构造各层的平面板片。不能将四个不共面点直接当真实玻璃，也不能随意三角化后称玻璃面板。
4. 标准大面板直接构造成竖直平面矩形，分别校核共面、法向Z分量接近0、相邻边正交及对边平行。最佳平面拟合仅用于诊断，不能把斜置梯形变为“合法标准板”。模型数值平面误差目标0.001 m仅为软件验收阈值，不是实物玻璃制造公差。局部异型板必须有单独板型依据；达不到规则则修正错台构造或标记未解决。
5. 从板片边生成独立框架，按图示设置400 mm环梁中心到控制线偏移；该值属早期设计，适用后期需注明跨版本假设。
6. 避开吊点、径撑、玻璃翅与竖梃冲突。早期G01版Z9不设玻璃翅、V口竖梃变化等例外由明确的版本规则控制；后期竣工映射未核验。
7. B层分区独立：早期设计提出1.0 m幕墙模块，而1.5 m是办公规划标准；后期候选及防火玻璃区域均保留来源适用范围。没有分配图时不自动铺满。
8. 块级材料可采用供应商2016玻璃层次，但不得据未分配的2100×2400 / 2100×4200 mm尺寸覆盖A/B全楼。

每个面板/合并网格面必须有可检索的 `panel_id / floor_id / zone / type_id / rule_id / source_ids / evidence / uncertainty`。为性能可每层或每区合并Mesh，不能丢失逐板追溯表。分格、框架、frit及节点可以分别开关。

## 8. 重生成与文件设计

后续实现采用Blender Python；当前没有生成脚本。

计划文件：`scripts/build_shanghai_tower.py`负责读取参数、清理自己创建的对象、调度生成和保存；`scripts/geometry.py`负责轮廓/变换/插值；`scripts/curtain_wall.py`负责板片/错台/例外；`scripts/validation.py`输出数据核验与相机图；参数集中于JSON，禁止散落隐式真实尺寸默认值。

命令行支持参数文件、输出目录、选用几何版本、Collection开关和研究/细节显示模式。运行时先输出证据等级统计、版本冲突、未知参数及占位部件。必需输入为null时，相应组件保持接口/占位并在报告中明示；不偷偷填数或整项跳过而声称完成。

从 `--factory-startup` 可重生成。重复构件由数据及规则生成；脚本重跑只删除带本项目ID的对象，保护当前其他作品。输出 `.blend`、源码、参数、验证JSON、视图和使用说明。

## 9. 阶段三、四的验收矩阵

| 检查 | 方法 | 可以证实的范围/尚需输入 |
|---|---|---|
| 建筑高度与标高 | 统一datum后核对包络极值、锚点残差 | 当前名义632；入口与设计零偏移未核验 |
| 楼层数 | 注册表统计、用途/夹层归属核对 | 124结构分析/127业主/128数据库口径保留；没有逐层表不能通过“真实层数”验收 |
| 典型与关键平面 | +45、33.45、99、173.70、239.40、314.10、393.30、465.40、542、573.90、605、632，按各自资料版本设置检查切片 | 部分检查高度已知但参考平面未取得；当前不能对该整套高度声称已有平面叠图或数值误差结论 |
| 旋转与收分 | 同一控制点逐标高角度/尺度及版本差异 | 线性/指数为设计机制；全楼坐标表尚缺 |
| 核心筒 | 九格/切角/十字/顶部形状与切换标高校核 | 拓扑可核验，内隔墙与洞口待图纸 |
| 主体与CWSS | 连接端点、按区挂接、杆径壁厚、连续环与滑移 | 设计规格可核验，坐标和逐区选型未齐 |
| 裙房接口 | 校准平面与剖面叠图 | B2–L4用途有据；外边界和屋顶标高待取得 |
| 幕墙近景 | 底/中/上各标准区域、V口、Z1/Z9、区界、防火区域；逐板统计、比例与平面残差 | 分格口径未统一，近景不能标为竣工匹配 |
| 参考对照 | 同比例正交平面/剖面、参考图叠加及残差表 | 摄影对比单独列拍摄模型/校正方法，不能视觉相似冒充精确匹配 |

数值0.001 m平面/端点误差、0.01°角度误差等为拟定软件测试目标；它们不代表输入数据精度。最终报告同时列数值生成误差、图像测量误差与来源/版本不确定性，未能量化时写“无法可靠量化”。

阶段四必须交付真实生成的模型视图和幕墙近景；本轮 `references/` 只有原资料参考图，不能当作已完成模型对照图。
