# v4塔冠图像复核与修订

2026-10-10联网检索并在浏览器实际查看以下图像：

- [Gensler：A Mayoral Visit to Shanghai Tower](https://www.gensler.com/a-mayoral-visit-to-shanghai-tower)，[冠边面板安装照片](https://static1.gensler.com/uploads/image/9369/filename/shanghai-tower-story_20141121_crane_1416614899.jpg)。原图1333×2000；文件名20141121，页面叙述施工期间接待活动，未把文件名当成正式图纸日期。作者官方一手施工照片，支持冠边较粗的连续边构件、格架和竖向钢构；不提供相机和尺度。
- [Cosentini Associates工程顾问官网](https://www.cosentini.com/)，[塔冠俯视图](https://www.cosentini.com/media/mod_zentools/cache/images/059Shanghai-Tower-547d0b02f7f07d20382582749fbac990.jpg)。原图1120×640，倾斜俯视，摄影时间、镜头参数和摄站未注明。顾问官网刊载项目照片，不是施工坐标来源。

俯视图可见开放的弯曲三角环、分裂的两唇和下收的内部壳面；结合NTUA剖面，本轮采用“背部弧段抬高、裂口两唇不等高”的形态解释。单幅倾斜照片的像素高度包含景深投影，不能单独证明绝对标高或唯一周向映射。此前“裂口端632m、背部中点610m”的映射未获图证，本轮以更符合这组视图的候选替换。

v4采用显式图像形态拟合：开放五弧s=0低唇610.194m，s=0.5背部峰632m，s=1高唇627.452m，以两段向下二次抛物线连接。632m仍来自公开项目高度；另外两标高沿用NTUA Fig8图测候选，不是从照片量出的精确高度。背部峰位s=0.5、起始唇方向和高低唇的模型对应均待确认；无真实北向/透视标定。

照片仅用于定性形态检查，没有执行像素到米的测量、单幅三维逆建或假称摄影校正。NTUA剖面的原像素、尺度39.530m/339px、约±1.5m候选误差仍见`research/crown_candidate.json`；其绝对高程版本偏差未消除。601.099m内屋面保留为独立剖面候选，不把它并入632m顶冠水平盖。

屋面径向坡使用各rim点的同一平面方位，避免从601m轮廓角额外扭至该点顶高造成二次角向剪切。外rim仍取所选母轮廓在自身z的变换；它与V接面的顶边应通过同一`trim_height`接口生成。增加开放rim边构件，半径0.12m是集中于`assembly_v3.json.crown`的显示参数，截面未证实。

修订可改善已发现的高低方向错误，不能证明恢复了竣工裁切曲线。外冠轮廓、集水壳、周向映射和边构件仍为候选，`asbuilt_verified=false`。需原始冠部CAD/BIM、测量坐标和相机标定图像才能定量复核。
