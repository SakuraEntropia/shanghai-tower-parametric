# 上海中心大厦：模型使用、实际核验与精度边界

交付日期：2026-10-10（Asia/Singapore）。已在本机Blender 5.2.0 Alpha实际生成、保存、重新打开并渲染。本文件描述研究交付版，不是竣工模型认证。

## 成果与限制

`model/shanghai_tower_evidence.blend`可编辑；`scripts/build_shanghai_tower.py`与同目录模块可从干净场景重生成。模型采用公开资料支持的推导母形、标准区幕墙推导、尺寸化独立样件和未确认接口。

**模型并非整栋建筑的完整实物复制。** 真实V口、0–45m下部、裙房、塔冠裁切、实际楼板/内皮半径表、核心墙线及主结构/CWSS真实坐标未取得，未伪造这些实体。顶端632m只是开放的诊断控制线；主塔实际标准带几何至541.90m。可见空档/余数不等于建筑真实退台或设备层。

+45m是本次研究覆盖起点，不是地面或真实Z2完整下边界。整个K2参考圆角被保守排除，**排除范围不是已复原的V口边界**。无V口的三重母形与真实外轮廓分别命名，不能把前者当成闭合竣工A轮廓。

## 组件与操作

打开 `.blend` 后，在Outliner逐集合开关。数字前缀按部件分组：核心控制体/内部接口、高区拓扑、主框架接口、CWSS样件/连接接口、标高/楼板接口、裙房接口、外轮廓、A幕墙玻璃/框架/闭合带、B幕墙接口、历史幕墙样件、核验相机。高区红色线框是未证实拓扑示意；灰色低区盒体是30m外包控制体，**不是实心混凝土核心筒**。

双击对象可看自定义属性：`source_ids`、`evidence_level`、`formula`、`uncertainty`、`geometry_role`、`asbuilt_verified`等。来源参数等级与安装定位等级分开。所有建筑相关对象均 `asbuilt_verified=false`。

Text Editor内有参数JSON、来源JSON、楼层锚点、实际配置、逐板台账、未知项、验证结果和生成脚本。参数与脚本不只留在对话中。原书本地路径仍保留，公开来源URL已嵌入；整个用户书籍没有复制进交付包。

米制1:1，Z向上，局部WP1=(0,0)。真实北向、入口/设计零点偏移未知。界面中模型可以自由编辑；编辑后应重跑相应核验，原交付检查结果不自动适用于新几何。

## 重生成

所有Python模块与JSON保持本目录相对位置。macOS命令：

```bash
cd /Users/faputa/Documents/Shanghai_Tower_Evidence_2026-10-10
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python scripts/build_shanghai_tower.py -- --config parameters/model_config.json --output model --render
python3 scripts/make_comparisons.py
/Applications/Blender.app/Contents/MacOS/Blender --background model/shanghai_tower_evidence.blend --python-exit-code 1 --python scripts/inspect_saved.py
```

其他操作系统替换Blender可执行路径。生成器采用标准bpy Mesh/Curve接口，本轮只实际验证本机5.2.0 Alpha；未声称跨版本兼容测试通过。Matplotlib/Pillow/Numpy仅用于外部参考对照图，生成blend本身无需这些第三方库。

不加 `--render`可只重建模型。修改 `model_config.json`的R1/L4/A1、版本端点、q、twist、显示配置；建筑输入变动需同步证据/公式/适用范围。采样数不是玻璃板数，幕墙带数不是实际楼层数。已确认尺寸的来源对照检查会报告被人为改动后的差异，不能把任意变体宣称资料一致。

2010/2014曲线支持独立纯几何计算；当前主塔幕墙场景是2014研究版。如果选择2010，必须同时调节核验截面到45–605m有效范围，并独立选择其历史幕墙输入，禁止只切换版本名而继续使用2014分格当作同版结果。未知完整楼层表/B半径/节点表目前只有接口，需要取得并导入后扩展生成器；本轮没有提供把null自动补齐的选项。

生成器重跑清理带本项目ID的对象；应从 `--factory-startup`运行。不会改动其他目录中已有用户模型。输出覆盖本项目同名文件；需要保留个人编辑时，先另存文件或指定新输出目录。

## 未能精确复现

- `above_ground_count`：统一真实地上楼层数。没有完整floor schedule和编号对照，不计算632/N。
- `level_crosswalk`：设计/监测/运营层号对应表。F51=239.40与运营52层约239m提示口径差异；不能统一+1或按楼号JOIN。
- `datum_offset`：设计零点到最低人行入口偏移。没有测量标高与±0统一文件。
- `notch_geometry`：缺口深度/端点与高度关系。不能固定等比例缺口；显著影响V口和局部分格。
- `inner_radius_table`：内幕墙各区半径IR。端径不足以恢复每区板边；不能等比连缩。
- `theta0_direction`：初始朝向和旋转正负。不可用远景印象选择后标真实朝向。
- `bottom_crown_curves`：底部与塔冠最终控制表。0–45/2010的605–632及塔冠裁切未知；不自动封顶为平盖。
- `core_partitions_openings`：核心内隔墙/洞口/截面切换表。九格不代表九个相同10m房间；空白出版图不能描摹。
- `inner_floor_profile_table`：各区楼板边界/退台及内皮坐标。不得用端值插值冒充各层实况。
- `mega_bottom_section`：巨柱基底截面。层位/版本差异未证实；不静默取值。
- `column_axes_sections`：逐层柱定位/内倾/截面。柱不能随外幕墙螺旋扭转；没有真正定位表。
- `truss_nodes`：主体环带/伸臂/径向承托节点坐标。数量/机制不提供可精确生成的全部杆件。
- `floor_schedule`：完整逐层结构/完成面标高表。没有平均层高冒充真实数值；未知部分暂缓。
- `podium_height`：裙房总高。38m未获得原PDF人工核验，禁止当确认值。
- `podium_boundary`：裙房各层边界/塔楼接口。基坑23460m²不等于建筑轮廓；不能等效圆/矩形。
- `cwss_hanger_positions`：逐区吊点数量/坐标。不能假定全楼24/25等角排布。
- `cwss_nodes_table`：铰/滑移/承托节点与自由度表。示意机制有据，但实际节点坐标/零件加工细图不齐。
- `cwA_perimeter_count`：外层每层统一实际板数。标准格/控制点/切口/整板统计口径不统一；不能默认全楼144。
- `cwB_grid_final`：后期内幕墙分格/防火/相切处规则。逐区圆筒折线、模块和防火区分配未公开。
- `frit_mapping`：彩釉点径/点距/区域与渐变分配。覆盖率不等于点径/点距；不得虚构均匀点阵。
- `curtain_exceptions`：幕墙局部例外索引。例外机制有据但缺板号/高度/尺寸表；不简单复制纹理。

施工图级复现所需文件见阶段一报告的9类清单：统一竣工坐标/高程、完整楼层对应、逐控制标高A/B曲线与V口、幕墙板号/材料/型材和全部例外、CWSS加工/定位、完整核心/巨柱/环带/伸臂图、裙房平剖面、批准玻璃与frit矢量网版、补齐损坏原图与校准竣工影像。取得后才能替换接口并重新评估精度。
