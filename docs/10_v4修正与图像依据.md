# v4：V凹面、塔冠、裙房修正

V口拓扑改为闭合的内凹玻璃表面，删除“整段K2是空洞”的解释。Gensler Fig3为正投影设计示意图，以WP1–WP2=47.665m校准；原图2100×1850px，轴点约(833,954)/(1680,954)，尺度0.05628m/px。两唇约(293,1669)/(482,1780)，尖点约(439,1640)，选线±4px约±0.23m。映射到解析母形grid20/26，并使用2014 Fig2.2已发布95°凹角，得默认45m处宽12.3656m、深5.6655m；这是条件图测推导，不是原CAD尺寸。拟合/版本候选误差约±0.6m，未量化的示意图系统误差另计。IR(z)完整表未知，当前采用母形缩放/旋转映射；局部分板、顶边剪裁、框截面均待确认。夹层环梁同时改随V内凹，避免仍在原圆角外侧穿出表皮。

塔冠采用照片与剖面共同支持的背部高峰、裂口低唇候选映射，并修正屋面额外角向剪切；632m名义指标保持，照片不用于假称精确高程。详见10_crown_v4.md。

裙房按Gensler实景航拍与单独标注的历史渲染改非对称曲面暖色屋面、低体量和开放庭院。相机未标定，平面尺寸/高度都是可调候选，D10早期7层38m不再套作最终照片裙房。详见10_podium_v4.md、podium_v4.json。
